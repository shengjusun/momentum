## 一、关于「官网」——结论：上架不要求官网

AGC 上架**不要求开发者提供官网**。唯一需要「一个可公开访问的网页」的地方是 **《用户协议》的协议链接**（协议服务里创建"用户协议"类型时，必须自己填 URL；隐私政策有华为托管，不用链接）。

三条路，按推荐度：

| 路径 | 说明 | 成本 | 风险 |
|---|---|---|---|
| ~~① 云托管海外站点~~ | **❌ 对本项目不可用** —— 站点类型由**项目的数据处理位置**决定：官方原文"创建海外站点：**当数据处理位置为德国、俄罗斯或新加坡时**……"；而本项目数据处理位置为**中国**（CloudDB 数据在中国），只能建中国站点 → 必须用自定义域名 | — | 排除（改数据处理位置会牵动整个项目与云端数据，不是换条路的事） |
| **① 第三方免费静态托管** | GitHub Pages / Cloudflare Pages / Vercel 等，传 `用户协议.html` 即可得公开 URL | 0 元、10 分钟 | 国内访问稳定性一般；**审核是否接受非华为托管的链接未知** → 工单第 1 题 |
| **② 自购域名 + ICP 备案** | 华为云/阿里云买域名（几十元/年）→ 华为云 ICP 备案（个人可办）→ 域名解析 TXT + CNAME → 云托管中国站点部署 | 几十元/年 + 2~4 周备案 | 周期最长，但域名可长期复用（用户协议、将来隐私页、帮助页、宣传页），且是**唯一确定被认可**的路径 |

**当前动作**：工单咨询中（核心问题已收敛为"**协议链接是否必须是华为云托管的页面，能否填写其他可公开访问的地址**"；若是 → 走路径②，若否 → 走路径①；同时问个人主体 ICP 备案要求与周期）。

**已备好的材料**：`docs/上架素材/用户协议.html`（自包含、零依赖）、`用户协议-site.zip`（根目录即 `index.html`，可直接部署）。
