# 起势 · 软著自办指引（中国版权保护中心，0 元）

> **适用**：个人开发者自办《计算机软件著作权登记证书》
> **目的**：AGC「版权信息」留档（实测非必填，不阻塞提审）+ 知识产权保护
> **依据**：中国版权保护中心官网（ccopyright.com.cn）、2026-03-15 新版申请表规范、华为审核要求（`developer.huawei.com/consumer/cn/doc/App/50111-02`）

---

## 0. 结论先行

| 项 | 值 |
|---|---|
| 费用 | **0 元**（2017 年起国家取消软著登记费） |
| 周期 | 受理 5–7 工作日 + 审查约 30–60 工作日 → **实际约 1.5–3 个月** |
| 是否阻塞提审 | **否**。AGC「版权信息」实测无必填标记，可先提审、并行办证 |

---

## 1. 入口

中国版权保护中心官网 → 注册/登录 → 著作权登记系统 → 选 **`R11 计算机软件著作权登记申请`**

同页其他项**都不是**你要的：

- R21 转让或专有许可合同登记 · R41 变更或补充登记 · R42/R43/R44 撤销/撤回 · R45 补发或更换证书 · R31 质权登记

---

## 2. 前置：实名认证

- 个人：身份证正反面 + 人脸核验
- 认证审核约 **1–3 个工作日**

---

## 3. 关键填写项（与华为上架名强相关）

| 字段 | 建议值 | 说明 |
|---|---|---|
| 软件全称 | **起势目标拆解管理软件** | 结构 = 品牌 + 用途 + 功能 + 后缀；建议 8–20 字；后缀优先「软件 / 系统 / 平台」 |
| **软件简称** | **起势** | ⭐ **最关键**：华为要求"软著证书上**名称或简称**需与上传的应用名称一致"。AGC 上架名 = `起势`，所以**简称必须填「起势」，不要留空** |
| 版本号 | `V1.0` | 须与源代码/文档**页眉**完全一致（有无 `V` 以申请表为准） |
| 软件作品说明 | 原创 | 首次登记选「原创」 |
| 开发方式 | 独立开发 | |
| 开发完成日期 / 首次发表日期 | 按实际 | 发表日期建议 ≤ 提审日 |
| **软件主要功能** | **500–1300 字** | ⚠️ 2026 新规硬性校验，**不足 500 字无法提交**；须写清研发背景 / 核心架构 / 功能模块 / 技术实现 / 应用场景；**禁止模板化、空洞化** |

---

## 4. 材料清单（全部 PDF）

1. **申请表签章页** —— 在线打印 → 本人签字 → 扫描上传
2. **源代码文档** —— 前 30 页 + 后 30 页（共 60 页，每页 ≥50 行；不足 60 页全部提交）
   - **页眉标注**：`起势目标拆解管理软件 V1.0`（与申请表完全一致）
   - 最后一页应为软件的退出/结束部分
   - 不得含第三方版权声明、开源协议头注释（如 GPL 头）
3. **软件文档**（三选一）—— 用户手册 / 操作说明书 / 设计说明书
   - **≥15 页，每页 ≥30 行**，含封面、目录、功能说明、界面截图；页眉同上
4. **身份证明** —— 身份证正反面扫描件（本人签字）
5. 可能要求：**《非职务开发证明》或《非职务开发保证书》** —— 按系统提示提交

---

## 5. ⚠️ 2026 新规的两个硬约束（务必先读）

1. **签章页手抄承诺**（2026-03-15 起）
   经办人须用**黑色中性笔亲笔抄写**承诺文本，并签名 + 填写身份证号。**严禁打印、代签、涂改**，否则申请材料无效。

2. **承诺内容含「未使用 AI 开发编写代码、撰写文档或生成登记申请材料」**
   并承诺"如有失实或欺骗，自愿承担**列入版权登记失信名单及个人征信记录**"。
   - 官方对"**涉 AI 辅助开发**"的口径：需补充**人工优化代码记录、训练数据合法证明**等佐证，否则面临补正甚至失信。
   - → **申请人须自行判断并如实处理，不要签署与事实不符的声明。**

---

## 6. 拿证之后

- 官网用户中心可下载**电子证书 PDF**（与纸质证书同等法律效力）
- 若华为后续要求上传：AGC → 版本信息 → 版权信息 → `应用版权证书或代理证书`
- 也可选择先到易版权走「**APP软著登记电子版权核发**」换电子版权认证证书（**免费，15 工作日**）
