## 3. 关键实现机制

### 3.1 状态管理（纯 V2，无 V1 混用）
- 4 个 ViewModel 全部 `@ObservedV2` + `@Trace`，以模块级 `export const` 单例导出，页面用**普通属性引用**获取响应式能力。
- 列表统一 `LazyForEach` + 自定义 `IDataSource`（手动 `notifyDataReload/Add/Change`）+ `@ReusableV2` 子组件 + `cachedCount`。**长列表性能规范到位**（Home 象限 / Route / GoalHistory / Notification / AI 对话）。
- 跨页通信走 `AppEventBus`（如 `TODO_COMPLETED`）而非直接耦合。

### 3.2 路由
- 全局单例 `globalNavStack: NavPathStack` + `ROUTE_NAME` / `TAB_INDEX` 常量集中管理。
- 跳转统一入口 `navigateTo / navigateToWithId / pushNavPath`，内置 **600ms 防抖**（`tryAcquireNavLock`）防连点重复压栈。
- `MainTab.PageMapBuilder` 用 `navDestination` 注册全部子页；参数经 `onDestinationReady(context)` 读取 `pathInfo.param`。
- 冷启动三条链路（通知直达 / 深链 / 多端流转）在 `EntryAbility` 统一调度，用 `pendingDeepLinkFlag` 协调「自动跳登录页」竞态。

### 3.3 数据持久化（工程质量较高）
- `StorageManager` 封装 ArkData preferences，**5 个分域 store**：`app_data_store` / `goals_store` / `todos_store` / `notify_store` / `pomo_store`，按 key 前缀自动路由，避免大 JSON 与小写入互相拖累。
- LRU 缓存（TTL 30s，上限 16）+ **写锁串行化**（同 key 写排队）+ **JSON 损坏回退 fallback**（不抛异常、不崩 UI）+ 一次性分域迁移（先 put 后 delete，最坏双份不丢数据）。
- 防抖统一 `PersistHelper`（200ms）。
- 桌面卡片走 `filesDir/card_snapshot.json` 明文快照（`HomeViewModel` 写、`EntryFormAbility` 读）。

### 3.4 网络与云端
- **客户端不持有 API Key**：AI 经 AGC 云函数 `calldeepseek` 中转，Key 在云函数环境变量（`DeepSeekService` 注释明示）。**全项目无硬编码密钥、无裸 URL。**
- AI 流式/多格式解析较强：兼容 `<plan>` / 代码块 JSON / 纯 JSON，含截断 JSON 修复、逐字段显式映射、完整错误分支（无 plan / 解析失败 / 限流 / 无效 Key / 服务不可用）。
- 云同步 `CloudSyncService.smartSync` 三向：`upload` 强制覆盖、`download` 强制覆盖、`merge` 按 id 并集（同 id 取 `updatedAt` 较新端），两阶段原子应用（解析失败整体放弃）。
- 认证双轨：`HuaweiAuthService`（华为账号）+ `AgcAuthService`（AGC 会话，`autoCreateUser` + hwid 补登），每个云操作前强制 `ensureSignedIn`，规避匿名「World 角色 2001015」。
- PII 脱敏：`Logger.secure` / `Logger.mask`（首尾保留 2 位）。

### 3.5 番茄钟与通知
- 前台 `setInterval` 1s，`onTick` 用 `Date.now()` 推算剩余（后台冻结可自愈）；`restoreSessionIfNeeded` 用 `savedAt` 重算（**支持进程被杀后恢复**）。
- 后台兜底 `reminderAgent.publishReminder`（由 `EntryAbility.onBackground` 登记），进程被杀也能到点通知。前台恢复时取消兜底。
- 站内通知 `NotificationCenterService` + 截止提醒 `DeadlineReminderService`（提前 5 天，通知 ID 段任务 [20000,30000)、目标 [30000,40000)、番茄钟 40000/50000）。

### 3.6 设备适配
- `BreakpointUtil`（mediaquery 监听 `min-width:600vp` / `840vp`）→ `breakpointState`（`@ObservedV2 @Trace` 单例，`breakpoint` + `isTablet`）→ 页面直接读 `breakpointState.isTablet` 响应式切布局。
- 关键设计：两个监听器**联合推导**断点，避免 lg 的 `false` 覆盖 md（注释已记录该坑）。
- `SafeAreaHelper` 存 `statusBarHeight` / `bottomSafeAreaHeight`，监听 `avoidAreaChange`（旋转/折叠自愈）。
- `sm`：单列 + 底部悬浮导航栏居中 72%；`md/lg`：双列/侧栏 + 导航栏靠左下 480vp。

### 3.7 隐私合规（设计优秀）
- 首启 `PrivacyConsentOverlay` 全屏阻断；**同意前 AGC 云 SDK 完全不初始化**，同意后才由 `CloudSdkService` 拉起——这是规范的「延迟初始化」合规做法。
- 不同意 → `terminateSelf()` 退出。设置页支持撤销同意、删除所有数据、清缓存。
