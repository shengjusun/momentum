## 三、三件套的两条"一致性"红线（最易踩坑）

- **实名一致性**：DeepSeek 账号实名（姓名 + 证件）必须 = 华为开发者账号实名。
  个人开发者 → 两边都是**你本人姓名**即可。
- **发票一致性**：发票「购买方」必须 = 开发者信息。DeepSeek 开票规则明确**抬头与实名信息一致** → 抬头类型选「**个人**」、抬头填**本人姓名**。

⚠️ 若 DeepSeek 账号是**企业实名**、或用的是**别人/公司的 Key**、或从未**充值** → 三件套会卡住。此时需先纠正账号实名。

## 四、DeepSeek 侧操作步骤（实名+充值约 10 分钟，发票约 7 个工作日）

1. 登录 `platform.deepseek.com` → 左侧 **Top up** → 若提示未实名，点 **Verify**
   - 认证类型选 **Individual（个人）**；填 **Real Name（真实姓名，中文）** + **二代身份证号** → Submit
2. **核对**：实名姓名 = 华为开发者实名姓名（**必须一致**）
3. **充值**：¥10 起（支付宝 / 微信）。建议充足以覆盖已消耗量
   - 开票上限 = 充值金额 − 已开票/开票中金额
4. **开票**：账单页 → 充值记录 → **申请发票**。⚠️ **默认是"企业"，必须改成"个人"**，逐字段如下：

   | 字段 | 填什么 |
   |---|---|
   | 开票方式 | **按充值金额开票**（一次开满，不必分次） |
   | 开票金额 | 直接填「可开票金额」上限（如 ¥110） |
   | 邮箱 | 你的常用邮箱（接收电子发票） |
   | 抬头类型 | **个人** ⚠️ 默认"企业"，必须切换 |
   | 开票类型 | **增值税普通发票**（个人选此项；专票需一般纳税人） |
   | 发票抬头 | **你的真实姓名**（= DeepSeek 实名 = 华为开发者实名） |
   | 纳税人识别号 | 个人普通发票通常可留空；若为必填按页面指引 |
   | 备注信息 | 可留空 |
   - 约 **7 个工作日**邮件发送电子发票
   - ⚠️ 提交前务必核对：**已开票金额不予退款；开票信息一经提交无法修改**
5. **截图留存**：① 实名认证信息页 ② API Key / 用量 / 账单页（证明"接入后台 API"）

## 五、结论与优先级

- **好消息**：最难的"合作协议"已获官方替代路径，**个人可办**；软著确认**非必选**。
- **真正的剩余硬骨头**：**《安全评估报告》+ 其平台提交通过截图**（官方必填、工单未豁免）。
- **建议优先级**：
  1. DeepSeek 实名 / 充值 / 开票（并行启动，等 7 天）
  2. 下载填写「个人开发者承诺函」
  3. build 后截「应用内 AI 显式标识」截图
  4. **优先启动《安全评估报告》**（唯一还需自己攻坚的项）
- 同时确认协议链接方案（见 `上架剩余事项清单.md` 第一节）与 APP 备案。
