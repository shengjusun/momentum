# 备案接入商咨询 · 华为云 + 腾讯云（可直接提交）

> 背景（2026-10-12）：已确认「跬步 / Momentum」**非单机应用**（有账号登录 + 云同步 + 外部 AI）⇒ 必须 APP 备案。
> 当前架构：后端 100% 在华为 AGC（CloudDB / 云函数 / 云存储 / 华为账号 / AGC 推送），**无自建服务器、无自有域名、无公网 IP**。
> 已核实规则（官方文档原文）：
> · 阿里云：「当您的互联网信息服务（网站、App）使用了阿里云中国内地云资源时，阿里云作为网络接入服务者才可为您提供备案服务。当您将互联网信息服务部署或托管在其他云厂商、互联网数据中心时，您需要联系您实际的网络接入提供商进行 ICP 备案。」
> · 腾讯云：「您的 APP 服务架设在腾讯云资源，则必须在腾讯云进行备案。」「若有多个接入商，需在每个接入商分别完成备案。」
> ⇒ 待决核心问题：本 App 的接入商是**华为云**还是其他？为此要不要买服务器、买哪家、域名怎么办。

## 四、答复 → 行动对照表

| 华为云答复 | 对应行动 |
|---|---|
| AGC 算华为云资源 / 有免服务器通道 | 直接在华为云备案，**不买任何服务器** |
| AGC 不算，但可用华为云服务器作备案载体 | 买华为云最便宜合规资源（包月 ≥3 个月），**后端继续留 AGC** |
| AGC 不算，且不接受该场景备案 | 转腾讯云 / 其他接入商路线（见下表） |

| 腾讯云答复 | 对应行动 |
|---|---|
| 轻量 + 自有域名可备案，且接受后端在 AGC | 买 38 元轻量 + 域名；把隐私政策/用户协议等静态页托管上去，作为「App 使用的域名」 |
| 必须把业务后端迁到腾讯云 | 评估迁移（客户端仅改传输层，2~4 周；详见迁移可行性分析） |
| 不接受该场景 | 放弃此路线，回华为云或寻找其他接入商 |

## 五、无论走哪家，都要提前办的两件事

1. **注册域名并完成个人实名认证**，实名主体必须与备案主体（孙胜举本人）完全一致（约 30~70 元/年）——APP 备案要求填写「App 使用的域名」，实名不一致会被退回；
2. 备案通过后 **30 天内**完成**公安联网备案**（全国互联网安全管理服务平台）。管局审核周期约 **20 个工作日**，请预留时间。

## 六、⚠️ 收到线上 AI 客服回复后的人工复核清单（必做）

> 2026-10-12：华为云线上 AI 客服已就上述 7 问给出初步答复（结论：AGC 不属于可备案的华为云资源；建议用「备案授权码」；推荐买 Flexus L 最小规格包月 3 个月；域名建议注册最便宜的）。该答复**属于 AI 推断，且存在自相矛盾与未覆盖的风险**，必须由人工客服复核以下 5 点后再据此下单。

**1. 授权码与服务器成本的关系（AI 答复自相矛盾）**
AI 说「没有服务器也可以用备案授权码」，但同一段又说授权码「由 ECS / Flexus 生成」「可向他人借用或自行购买生成」⇒ **结论仍是「要么借到、要么自己买服务器」**，并未省掉这笔支出。
请人工确认：
- 华为云**个人实名账号**能否生成备案授权码？（腾讯云明确：个人账号不允许生成）
- 若借用他人授权码，出借方是否必须是**企业实名账号**？出借是否被官方允许？

**2. 借用授权码的真实风险（AI 完全未提）**
- 出借方服务器**到期、欠费、释放**后，我借来的授权码对应的备案会不会被**取消接入 / 注销**？
- 备案主体是我、资源归属是他人，主管部门核查时会不会被认定为**「备案信息与实际不符」**？
- 有没有更稳妥、且**确实不需要任何服务器**的备案通道？（请明确回答「有 / 没有」）

**3. APP 备案的域名栏是否必填（AI 自己也未确认）**
AI 答复为「建议注册一个最便宜的域名，该域名无需实际解析或搭建网站，仅作备案关联用途」，但同时要求「咨询备案客服确认是否必填」⇒ 未给出确定结论。请人工确认：
- 华为云 APP 备案表单，**域名一栏是否强制必填**？
- 若必填：是否**必须解析**到服务器？是否必须在 App 内**实际使用**该域名（例如隐私政策页 / 接口）？
- 使用 .top / .xyz 等低价后缀是否可行（部分管局对后缀有要求）？域名注册商是否必须为境内？

**4. 服务器位置与实际资源的矛盾**
AI 建议「服务器位置」选「您的 APP 服务器在中国大陆」。但我名下**没有任何中国大陆服务器资源**（只有 AGC）。请确认这样填写是否成立、是否会被初审或核查驳回。
（另请自查：AGC 项目「数据处理位置」是否已设为「中国」——`PushTokenProbe.ets` 中错误码 `1000900013` 即提示「数据处理位置需设为中国」。）

**5. 备案号展示与平台标识的落地要求**
- AI 提到备案号须在 App **显著位置标注并链接备案系统网址**：请给出**具体要求与示例格式**（链接地址是哪个、是否必须可点击跳转）。
- 请确认：鸿蒙平台备案在华为云系统中如何选择（是否选「鸿蒙」并填包名）。
- 请确认：本项目**没有元服务**（只有应用内服务卡片），是否无需额外备案。
- 请索要 AI 引用内容的**官方 FAQ 原文链接**（AI 引用中的「用云函数和数据库生成的服务端该如何备案」场景指的是华为云云函数，与 AGC 云函数并非同一产品，适用性需核实）。

**⚠️ 一个必须提前知晓的备案时间口径**：官方口径为服务商初审 3~5 个工作日 + 管局审核最长 **20 个工作日**（AI 回复的「5~25 工作日」偏乐观），上架排期请按最长口径预留。
