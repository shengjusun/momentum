## 四、在线申请 8 步

**入口**：中国版权保护中心著作权登记系统 <https://register.ccopyright.com.cn>

1. **注册**：进入系统 → 选择身份时选**「个人」**（不是"机构"）→ 填用户名、手机号、验证码、密码。
2. **实名认证**：注册后按指引完成实名认证（个人需真实姓名 + 身份证信息）。**未完成实名认证无法提交业务**。
3. **选业务**：登录后在"去登记"里选择**计算机软件著作权登记**。
4. **在线填报**：按第五节的对照表逐项填写。
5. **打印签章页**：系统生成《申请确认签章页》→ **在线打印**（不要自行改动内容、格式和打印比例）→ **本人签字** → 扫描成 PDF。
6. **上传材料**（共 4 类）：
   - 申请确认签章页（签字后的扫描件，PDF）
   - 身份证明：**身份证复印件（正反面）并本人签字**，拍照或扫描
   - 源程序鉴别材料 → 上传 `起势任务管理软件V1.0-源程序.pdf`
   - 文档鉴别材料 → 上传 `起势任务管理软件V1.0-使用说明书.pdf`
7. **提交**，等待**受理**。材料不齐或不符会被**不予受理**（例如签章页无签章）。
8. **跟踪与取证**：受理后 60 日内完成审查；通过后可在**用户中心下载电子证书（PDF）**，并可在官网查阅登记公告。

### 主要功能和技术特点（可直接粘贴）

> 本软件是一款运行于 HarmonyOS 平台的目标管理与专注效率应用，面向个人用户提供从目标设定到任务执行的完整闭环，主要包括六项功能：一是目标管理，支持创建长期目标并设置分类、期望完成时间与进度，并在目标下维护任务清单；二是任务与步骤管理，支持把任务拆分为可逐条勾选的执行步骤，自动汇总步骤进度并联动更新任务状态与目标进度；三是艾森豪威尔四象限，按重要与紧急两个维度自动归类当日待办并给出处理优先级；四是智能辅助，支持以自然语言描述目标，由已备案的第三方大模型服务生成结构化的任务清单与执行步骤，并提供目标阶段复盘与每日任务排序建议，生成内容按监管要求进行显式标识并提供举报入口；五是番茄钟专注，内置番茄工作法计时器，支持专注、短休息、长休息三阶段自动轮转，提供沉浸式全屏界面、到点提醒与专注统计，并在屏幕方向变化时自适应布局；六是数据统计与备份，按日、周、月统计任务完成情况与专注时长，支持全部业务数据的导出与导入。
>
> 技术特点：采用 ArkTS 声明式开发框架与 MVVM 分层架构，使用关系型数据库进行本地持久化，采用响应式断点布局适配手机与平板的四种屏幕形态，支持浅色与深色外观跟随系统；在隐私设计上遵循最小必要原则，本地数据保存在应用沙箱内，调用第三方大模型服务时仅发送必要的文本与统计数据，不发送目标名称、任务名称等可识别文本。

## 七、五个容易踩的坑

1. **姓名必须处处一致**：申请的著作权人姓名、身份证、DeepSeek 实名、华为开发者实名 —— 全部是**同一个真实姓名**。不一致会在后续环节互相卡住。
2. **日期不能穿越**：源程序与说明书里出现的日期必须**不晚于**"开发完成日期"。所以填 2026-09-14（今天）；**不要把开发完成日期往前填**。
3. **名称必须字字一致**：源程序 PDF、说明书 PDF 的页眉，与申请表里的"软件全称"必须是同一串字符。目前已按 `起势任务管理软件` 统一生成；若要改名，**必须用生成脚本重出两份 PDF**，不要手改 PDF。
4. **签章页必须签**：官方明确"申请确认签章页无签章的视为未提交相应材料，不予受理"。打印后**本人签字**再扫描。
5. **身份证复印件要签字**：自然人申请人提交身份证复印件时需**本人签字**。
