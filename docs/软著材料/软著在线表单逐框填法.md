```
本软件是一款运行于 HarmonyOS 平台的目标管理与专注效率应用，面向个人用户提供从目标设定到任务执行的完整闭环。一、目标管理。用户可创建长期目标，设置名称、所属分类、期望完成时间与描述。目标列表以卡片展示目标名称、分类、进度百分比、期望完成时间与任务完成情况，进度同时以环形图与数字呈现。列表上方提供分类筛选，用户可查看全部或某一分类下的目标，并可编辑与删除目标，删除前软件明确提示将同时移除该目标下的全部任务与步骤。二、任务与步骤管理。每个目标下可维护任务清单，每个任务可进一步拆分为若干可独立勾选的执行步骤。用户逐条勾选步骤完成情况，软件自动汇总已完成步骤数与总步骤数并更新任务进度；当任务下全部步骤完成时，任务状态自动标记为已完成，目标进度随之同步刷新。步骤支持新增、编辑与删除。三、艾森豪威尔四象限。软件按重要与紧急两个维度把当日待办任务自动归入四个象限。用户可在任务详情中调整任务的重要与紧急属性，调整后任务自动移动到对应象限，帮助用户快速判断处理顺序。四、智能辅助。用户可用自然语言描述目标或需求，软件调用已通过国家备案的第三方大模型服务生成结构化的任务清单与执行步骤，每条任务包含名称、优先级、预计耗时与执行步骤。方案以卡片形式呈现，支持展开与收起，并支持对单条任务微调或删除；用户确认后，方案下的全部任务与步骤一次性写入目标。软件同时提供目标阶段性复盘与每日任务排序建议。按监管要求，人工智能生成的内容在界面上进行显式标识并提供举报入口。五、番茄钟专注。软件内置番茄工作法计时器，支持专注、短休息、长休息三种阶段按设定轮次自动轮转。用户可选择各阶段时长与长休息前的周期次数，设定会被保存以便下次沿用。计时过程支持暂停与继续，停止需二次确认。软件提供沉浸式全屏界面，进入专注后控件在数秒无操作后自动淡出，系统状态栏与导航栏同时隐藏，点击屏幕可重新唤出；专注期间保持屏幕常亮，退出后自动解除。专注结束时在系统中登记提醒，切出软件或锁屏也能收到到点提醒，并记录当日专注次数与累计时长。六、数据统计与备份。软件按日、周、月等维度统计累计完成的任务数量、目标完成情况、累计专注次数与累计专注时长，以数字卡片与趋势图展示。软件还提供全局回顾，生成整体性评价与建议。数据备份方面，用户可将全部业务数据导出为备份文件，也可以在更换设备或需要恢复时导入该文件。
```

## 附：字数是怎么算的
