## 一、🔴 上架阻断项（审核会直接挂）

### 1. 全应用强制登录 + 拒绝登录无法退出（B1，违反《华为帐号登录管理细则》）
- `MainTab.ets:144-154` 冷启动守卫强制跳登录
- **`LoginPage.ets:306-318` 拦截系统返回键**，未登录弹"请先登录应用"并 `return true` —— **登录页没有任何"取消/暂不登录/退出"选项**
- 细则原文："当应用调用帐号登录功能时，应提供清晰的取消或拒绝选项按钮，**不得强制要求用户登录帐号才能使用**"
- 核心功能（四象限/番茄钟/本地数据）不登录完全可用 → 账号非必需 → 叠加《个人信息保护法》第 16 条风险
- 另有 2 个绕过口使"截断"不严密：深链/通知直达可跳过登录守卫（`MainTab:149-152` + `EntryAbility` 的 `executeNotificationRoute` 与登录态无关）；冷启动 500ms 窗口主界面已可见可点

### 2. AIGC 合规四件套缺失（报告完全未提，比登录更致命）
AI 拆解属官方定义的"深度合成/生成式人工智能服务"（篇章生成、问答对话），按《部分类型应用注意事项》17：
- [ ] **无"举报"入口** —— 全项目 grep `举报|投诉` 为 0。官方明确"问题反馈"**不等同于**举报，必须用"举报"字样
- [ ] **AI 生成内容无显式标识** —— 仅有分类标签"AI 生成"（`ai_category`），不构成内容标识要求
- [ ] **未配置 AGC「AI 功能声明」** —— 应用上架 → 版本信息 → AI 功能声明，需选"涉及"并上传标识材料
- [ ] **资质材料缺失** —— DeepSeek 算法备案（生成合成类，beian.cac.gov.cn 查询截图 ✅ 已取得）+ 合作协议（含算法名称/备案编号）+ 《安全评估报告》及全国互联网安全服务管理平台"通过"截图
  - **2026-09-14 华为官方群答复（定论）**：① 合作协议**通常是需要的**；② 算法备案截图 / 调用量截图 / 把备案号写进用户协议等**替代不了合作协议**；③ **软著为非必选资质，不阻塞上架，可上架后再提交**
  - → 行动：向 DeepSeek（api-service@deepseek.com）申请「算法技术支持说明/授权确认」；同时在华为群追问"个人开发者直接调用已备案大模型开放平台 API、无纸质合同，合作协议可用什么形式提供"（群里说不行，不代表华为没有针对个人开发者的受理形式，需工单留档确认）
- [ ] 用户服务协议中未说明标识规范（且当前**《用户协议》链接直接展示隐私政策内容**，见 §四-3）

### 3. release 构建链未就绪（H4 + H5）
- 混淆关闭（`entry/build-profile.json5` `enable:false`，规则文件已写好）

### 4. 隐私政策与实际数据处理不符（H3，本轮我只修了一半）
